# 保持健康索引

## 文档清单

| 文档名称 | 内容概括 |
| --- | --- |
| `饮食-主题.md` | 记录认为适合自己的健康食物、搭配、食用方式与实际体验。 |
| `饮品-主题.md` | 记录认为比较健康的饮品、饮用场景、注意事项与体验。 |
| `习惯-主题.md` | 记录有助于保持健康的生活习惯、执行方法、效果与待调整之处。 |

本目录用于集中整理与“保持健康”有关的个人资料和实践记录，包括比较健康的饮食、饮品以及生活习惯。记录时尽量区分可核验的信息、自己的实际体验和仍需验证的判断：来源或营养信息明确的内容可链接到事实库；个人感受、执行过程和效果可保留在日记或本目录的记录中；对是否适合自己尚不确定的内容，应标注“待核验”，不要把个人经验直接当成普遍结论。后续可以按主题拆分笔记，并在本索引中持续补充文档名称和简要说明。
