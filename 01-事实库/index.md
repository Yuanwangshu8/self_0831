# 事实库索引

## 文档清单

| 文档名称 | 内容概括 |
| --- | --- |
| `来源记录-YYYY-MM-DD-主题.md` | 一条可追溯资料的原文摘录、链接、时间与可信度说明。 |
| `观察记录-YYYY-MM-DD-主题.md` | 个人直接观察到的事件、数据或现场信息。 |

此目录保存能够被来源、记录或证据支撑的信息，是全部笔记的稳定底座。每篇文档应注明记录日期、信息来源、原始链接或附件位置，以及事实与个人解读的边界；无法确认的内容要标记为“待核验”。事实一旦写入，原则上不得直接修改或润色原有表述，以保留当时的证据和上下文；若发现错误、获得补充或需要更正，请另建一篇更正记录，并链接回原文。不要在这里写长篇推测、行动计划或情绪感受，它们分别进入推理区、工作任务、项目或日记。引用本目录时，应尽量链接到具体笔记和小节，确保日后能够回溯判断依据。
