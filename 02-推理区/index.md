# 推理区索引

## 文档清单

| 文档名称 | 内容概括 |
| --- | --- |
| `判断-数据库端口仅向必要主机开放.md` | 记录数据库端口按最小必要范围开放的安全判断、推导依据、待核验配置和后续验证动作。 |
| `分析-主题.md` | 围绕单一问题整理证据、假设、推导过程和暂定结论。 |
| `决策记录-主题.md` | 记录一个选择的备选方案、判断依据、决定与复盘节点。 |

此目录用于把事实转化为有限范围内、可检查的判断。每篇推理笔记先定义要回答的问题，再链接事实库中的证据，明确哪些是已知事实、哪些是假设、哪些仍待验证；结论应标注信心程度和下一步验证动作。推理要服务于一个具体问题或决策，避免把无关想法不断堆入同一篇笔记；出现新主题时另建文档并互相链接。这里可以修订，因为推理会随证据更新，但不得悄悄篡改事实库原文。若结论最终转化为具体行动，请链接到工作任务或项目笔记；若只是灵感而尚未成形，可先放入收件箱后再决定归属。
