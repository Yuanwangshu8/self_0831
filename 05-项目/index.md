# 项目索引

## 文档清单

| 文档名称 | 内容概括 |
| --- | --- |
| `项目-项目名.md` | 一个项目的目标、范围、里程碑、资料链接、进度与成果。 |
| `项目复盘-项目名.md` | 项目结束后的结果、经验、问题和可复用做法。 |

此目录保存具有明确目标、持续周期和多个关联任务的项目资料。每个项目先建立一篇总览笔记，说明项目背景、目标、完成标准、范围边界、关键里程碑、当前状态和负责人；再把具体执行工作链接到工作任务目录。项目笔记是导航页，而不是把所有会议、资料和想法重复复制进来：原始证据放事实库，分析判断放推理区，个人感受放日记，行动项放工作任务。项目过程中可以随进展更新计划和状态，但应保留重要决策或变更的时间记录。项目结束后添加成果链接与复盘，并将仍有价值的经验提炼为独立知识或模板，方便未来项目复用。
