# 工作任务索引

## 文档清单

| 文档名称 | 内容概括 |
| --- | --- |
| `任务-主题.md` | 单项待办的目标、截止时间、下一步、状态与交付链接。 |
| `周计划-YYYY-Www.md` | 本周优先级、任务安排、风险和完成回顾。 |
| `任务-宜昌教师岗位联系清单.md` | 面向2027届华中师范大学学科教学（物理）硕士的宜昌教师求职任务页。记录从人才引进岗位表中筛出的5所市直教育系统学校、9个高中物理教师岗位计划、联系人和电话，区分可直接联系岗位与当前博士学历不匹配的岗位，并提供咨询话术、材料清单、联系记录和后续复查节点。 |

此目录管理可以执行、跟踪和交付的工作事项。每个任务笔记应有清晰目标、当前状态、下一步最小行动、截止时间或复查日期，以及相关项目、事实或决策记录的链接；状态可使用“待办、进行中、等待、已完成、已取消”。任务要写得足够小，使自己或 AI 能据此直接推进，复杂事项应拆分为多个任务或提升为项目。完成后保留交付物位置、结果与简短复盘，不要删除历史，以便估算后续工作。这里重点是行动管理而非长篇论证：背景分析应链接推理区，客观依据应链接事实库。定期用周计划审视优先级，避免任务列表无限堆积。
