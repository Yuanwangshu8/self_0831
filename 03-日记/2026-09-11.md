## 读书笔记

书读得好，不代表事情能处理得好；能列出计划，也不代表能执行计划。

读书和规划提供的是理解与方向，而处理具体事情、把计划落到行动上，还需要在真实情境中练习、调整并持续执行。

## 待核验的想法：用 Hermes 远程书写读书笔记

我想在 Obsidian 中做读书笔记，并通过 Hermes 实现远程书写。

今天发现，Hermes 部署在另一台服务器上。为了让它读取和写入我的本地笔记文件，我目前想到或许需要通过 Git 同步文件；但这只是尚未验证的设想。

我也经常遇到“写入工具因本机沙盒初始化异常无法使用”的提示，目前不确定这是否与 Git 有关，仍需排查。

老师推荐了类似 GitHub 的网站：[Gitee](https://gitee.com/)。明天想试着了解并验证它是否适合这个使用场景。
